# AI Studio Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the ad page's AI tools to a new AI Studio page and add a fal video playground paid from the AI-video seconds.

**Architecture:** A new route `/dashboard/studio` with three tabs reuses the existing `AdVideoAnalysis` tools unchanged and adds a
Playground backed by a new `studioClips` table and a Convex pipeline (`convex/studio.ts`) that mirrors `convex/remake.ts`
(charge at start, scheduled `advance` polling fal every 10 s, copy MP4 into storage). Allowance and caps are shared with remakes.

**Tech Stack:** React + Vite + shadcn/ui (`src/`), Convex (`convex/`), fal queue API (`convex/lib/fal.ts`), vitest + convex-test.

**Spec:** `docs/superpowers/specs/2026-10-21-ai-studio-design.md`

## Global Constraints

- Commands (from `CLAUDE.md`): `npx vitest run <files>`, `npx tsc --noEmit -p convex`, `npx tsc -b`, `npx eslint <files>`. pnpm isn't installed.
- Commit with `git -c user.name="ahmadmibayyad-blip" -c user.email="ahmadmibayyad@gmail.com" commit ...`.
- No `Array.prototype.at()` in `convex/` (CI's lib < es2022). Test Response bodies: `new Uint8Array(...)`.
- Prompt max 1,500 characters. Photo: JPG/PNG/WebP under 8 MB (reuse `photoProblem` from `convex/lib/remake.ts`).
- Seconds charged = `ceil(length × multiplier)`, minimum 1. Multipliers: kling-2.5 ×0.5, kling-3 ×1, seedance ×1, h3-turbo ×0.5.
- Stale after 20 min (`STALE_MS`), poll every 10 s (`POLL_MS`) — import both from `convex/lib/remake.ts`.
- Error copy, verbatim: "AI video isn't switched on yet (FAL_KEY).", "AI videos come with Pro.", "Your last video is still being made.",
  "Describe the video first.", "Pick a model from the list.", "Pick a length this model makes.", "Pick a format this model makes.",
  "Add a product photo for this model."
- UI copy, verbatim: sidebar "AI Studio"; tabs "Remake an ad", "Playground", "My videos"; ad page button "Open in AI Studio";
  buttons "Generate", "Re-roll", "Other model", "Download MP4"; no-ad note "Open an ad in Ad Spy and click Open in AI Studio to remake it here."
- No Veo in v1.

## Review Focus

1. A remake running blocks a playground clip and vice versa ("Your last video is still being made.") — pinned in Task 3.
2. The seconds-left counter (`remake.allowance`) includes clip seconds; a failed clip gives them back — pinned in Task 3.
3. A model whose text-to-video endpoint doesn't exist is refused without a photo ("Add a product photo for this model.") — pinned in Task 1.
4. Opening the studio with a bad or someone else's `?ad=` id shows "Ad not found" instead of crashing — pinned in Task 5.
5. Re-roll sends a different seed than the take it re-rolls — pinned in Task 3.

### Task 1: Model catalog and rules (`convex/lib/studio.ts`)

**Files:**
- Create: `convex/lib/studio.ts`, `convex/lib/studio.test.ts`

**Interfaces:**
- Produces:
  - `type StudioModelKey = "kling-2.5" | "kling-3" | "seedance" | "h3-turbo"`
  - `type Aspect = "9:16" | "1:1" | "16:9"`
  - `type StudioModel = { key: StudioModelKey; name: string; blurb: string; imageEndpoint: string; textEndpoint: string | null; lengths: number[]; aspects: Aspect[] | null /* null = follows the photo */; multiplier: number; seeded: boolean }`
  - `STUDIO_MODELS: StudioModel[]`, `MAX_PROMPT = 1500`
  - `type StudioRequest = { model: string; prompt: string; aspect: string; length: number; hasPhoto: boolean }`
  - `validateRequest(r: StudioRequest): { model: StudioModel; prompt: string; aspect: Aspect; length: number }` — throws `Error` with the exact copy from Global Constraints
  - `chargeFor(model: StudioModel, length: number): number`
  - `falInput(model: StudioModel, r: { prompt: string; aspect: Aspect; length: number }, imageUrl: string | null, seed: number | null): { endpoint: string; body: Record<string, unknown> }`

- Produces:
  - `studio.models` query → `{ key, name, blurb, lengths, aspects, multiplier, needsPhoto: boolean }[]`
  - `studio.start` mutation `{ model: string; prompt: string; aspect: string; length: number; imageId?: Id<"_storage">; seed?: number }` → `Id<"studioClips">`. No `seed` given = random `Math.floor(Math.random() * 2_147_483_647)` for seeded models.
  - `studio.latest` query `{}` → `{ _id, status, error, videoUrl, model, prompt, aspect, length, seed, imageId, seconds } | null` (stale shown as failed)
  - `studio.mine` query `{ paginationOpts }`-free: `{ limit?: number }` (default 30, max 60) → `{ kind: "ugc" | "clip"; id: string; title: string; videoUrl: string; at: number; adId?: Id<"ads"> }[]` newest first, done rows of both tables.
  - internal `studio.load`, `studio.patch`, `studio.advance` (same shape as remake's).
